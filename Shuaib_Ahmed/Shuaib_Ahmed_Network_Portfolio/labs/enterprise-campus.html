Enterprise network lab report

Resilient Enterprise Campus Network

A Cisco EVE-NG campus build integrating VLAN segmentation, 802.1Q trunks, Rapid PVST+, HSRP, OSPF, redundant edge routing, and simulated ISP connectivity.

Problem statement

Design a resilient campus network for a growing organization.

A growing organization needed a more scalable campus architecture than a flat access-layer design. The network had to segment departments into separate VLANs, provide redundant default gateways, maintain routing during edge or distribution-path failures, and support a clean validation process that proves Layer 2, Layer 3, and WAN reachability.

The target design needed to support multiple access switches, redundant distribution switching, dual distribution routers, dual edge routers, and a simulated ISP path without relying on a single upstream device.

Requirements mapped to the solution

SegmentationVLANs 10, 20, 30, 40, and 50 separate endpoint groups and reduce broadcast-domain scope.
Layer 2 resiliencyRapid PVST+ controls loop-free forwarding and places DSW1 as primary root with DSW2 as secondary/root-path backup.
Gateway redundancyHSRP provides a stable virtual gateway address for each VLAN while DIST-RTR1 and DIST-RTR2 maintain real routed addresses.
Dynamic routingOSPF area 0 advertises campus VLANs and routed uplinks between distribution and edge routers.
WAN reachabilityEDGE1 and EDGE2 connect to ISP-RTR and advertise/default-route campus traffic toward simulated internet loopbacks.

Core configuration patterns

The campus uses repeatable Cisco IOS patterns: explicit static trunks, native VLAN 99, Rapid PVST+, edge-port hardening, HSRP virtual gateways, and OSPF with passive interfaces by default.

Validation evidence

The screenshots below document the deployed state: access VLANs, trunking, STP root behavior, router-on-a-stick interfaces, HSRP state, OSPF neighbor/route learning, edge reachability, and ISP return routing.

Operational result

  • Access switches provide endpoint-facing VLAN segmentation with trunks back to the distribution layer.
  • DSW1 and DSW2 maintain a deterministic Rapid PVST+ topology instead of leaving root election to default MAC-address behavior.
  • DIST-RTR1 and DIST-RTR2 provide redundant first-hop gateway behavior through HSRP.
  • OSPF dynamically distributes campus and transit routes through the routed distribution/edge layer.
  • EDGE1, EDGE2, and ISP-RTR validate northbound reachability and simulated internet return routing.

Evidence boundary

Redundancy is configured; a failover event is not shown.

The screenshots establish active/standby HSRP state, routed redundancy, and ISP reachability. They do not include a deliberate link or device failure followed by recovery measurements, so this report does not claim that a failover test passed.
