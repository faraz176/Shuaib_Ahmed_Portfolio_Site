Offline Security Evidence Verification

A read-only Python workflow for independently reproducing selected security-exercise results from supplied artifacts, then checking the reasoning before accepting an answer.

Outcome

Ten selected results independently reproduced and classroom-confirmed.

I used a local verification harness to work through ten selected exercises using supplied logs, scan output, and encoded artifacts. Each selected result was accepted by the ungraded classroom checker at 1/1 point. The checker did not affect the assignment or course grade, and the later submission record remained pending evaluation.

Verification workflow

Transform, correlate, cross-check, and preserve provenance.

  1. Decode with round trips. Apply encoding transforms and assert that decoding the derived value reproduces the original bytes.
  2. Inspect supplied logs. Extract unique client versions rather than rely on a visually repeated row.
  3. Correlate scan formats. Compare Nmap text output against structured XML service records rather than treating either as self-explanatory.
  4. Record source identity. Save artifact byte counts and SHA-256 hashes with the results.
  5. Compare acceptance separately. Keep local reasoning distinct from the classroom acceptance record.

Negative evidence matters

One unresolved count-based exercise stayed out of the solved list.

The verifier tried literal, regular-expression, line-based, and parsed-field counting approaches. They did not establish a reliable answer, so that exercise remained unresolved instead of being promoted into the results to improve the headline.

That exclusion is part of the engineering result: a failed independent check is a reason to revisit the method, not permission to hide the discrepancy.

Security and publication boundary

Publish the method, not the answer set or target details.

This page deliberately omits challenge answers, classroom identifiers, raw logs, target addresses, service versions tied to targets, and the original verification scripts. The work demonstrates offline analysis of supplied artifacts, not live exploitation, production security operations, or an instructor-awarded grade.
